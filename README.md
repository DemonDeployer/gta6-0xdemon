**Neon Bay** is a top-down 2D open-world crime game: a sun-soaked procedural city to explore on foot and by car, with traffic, pedestrians, a 5-star wanted system with pursuing Bay PD, a 10-job chain (6 story missions against a $50,000 debt, then 4 side jobs: taxi fares, a neon street race, a delivery run, and vigilante work), combat, a day/night cycle with neon lights and headlights, a Pay 'n Spray garage that clears your wanted level for $200, 7 vehicle types (sedans, sports cars, taxis, trucks, vans, motorbikes, police cruisers) with distinct handling, named districts, a minimap HUD with a clock, synthesized sound and music, and save/load — all in vanilla JavaScript with no libraries and no network requests.

## Run it
```sh
node serve.ts
```
(open http://localhost:8080)
