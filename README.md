**Neon Bay** is a top-down 2D open-world crime game: a sun-soaked procedural city to explore on foot and by car, with traffic, pedestrians, a 5-star wanted system with pursuing Bay PD, a 6-mission story chain, combat, a minimap HUD, synthesized sound, and save/load — all in vanilla JavaScript with no libraries and no network requests.

## Run it
```sh
node serve.ts
```
(open http://localhost:8080)
